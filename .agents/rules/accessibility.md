# Acessibilidade

- Todo `input` tem `label` associado.
- Todo `button` tem texto ou `aria-label`.
- Imagens com `alt` descritivo (ou `alt=""` se decorativa).
- Navegação por teclado funcional em menus e formulários.
- Usar componentes Mantine sempre que possível — já vêm com acessibilidade.
- Preferir localizadores semânticos em testes para reforçar a acessibilidade.
